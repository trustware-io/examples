# Trustware V1 Examples

V1 examples are grouped by integration surface:

- [SDK examples](./sdk) for React/TypeScript integrations using `@trustware/sdk`.
- [REST API examples](./api/rest) for direct HTTP integrations in any language.

Use REST examples when you want full backend control over route creation, receipt submission, status polling, balances, and prices. Use SDK examples when you want Trustware wallet detection, widget UI, or the headless TypeScript client.
